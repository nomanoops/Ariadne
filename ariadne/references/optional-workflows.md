# Optional discovery, comparison, notes and continuity

These practices are conditional on the learning aim, accessible sources, host capabilities and user authorization. They do not make a project or storage system a prerequisite for philosophical teaching.

## Source discovery

For broad exploration, search a proportionate variety of formulations and perspectives if retrieval is actually available. Start with the primary work and reliable orientation appropriate to the question; look for significant specialist or competing interpretations where a real interpretive boundary warrants them. Do not impose a numerical source quota, fabricate a scholarly debate, or describe an abstract as a full reading. Record source identity, edition, location, access level, relevant range, contribution, and uncertainty. A lead, locally present file, readable text, inspected section and fully read source are distinct. If a required source is absent, state the narrow consequence, offer lawful access help or ask the learner for the relevant authorized material. A package can be useful while broader discovery remains incomplete; do not claim complete corpus adequacy.

Where competing interpretations could materially change understanding, identify each source's question, thesis, primary textual evidence, key inferential step, rival response and vulnerability. Check whether they answer the same question, are genuinely incompatible, or could be layered. Read relevant sections on both sides where available; identify asymmetry and avoid final adjudication from an overview or abstract alone. Return important interpretive differences to the primary text. A citation chain is a bounded discovery method, not a substitute for reading; stop when it no longer changes the decision at hand. Record a negative search only with its actual scope and method.

## Existing notes and cards

If the learner permits and a host really offers access, retrieve relevant prior notes read-only to learn what was previously recorded; do not treat a filename, tag, link or single keyword hit as comprehension, or stored knowledge as present mastery. Use this evidence to avoid unnecessary repetition, with a short retrieval check only where it changes teaching. Preserve the provenance and scope of the learner's prior statements.

A useful note or card may capture a learner-generated insight, relevant primary evidence, agent calibration and unresolved question separately. Suggest or draft it when appropriate, but a suggestion is not a stored or committed card. Ask before modifying the user's note store, files or projects and follow any more restrictive instructions. Never invent tool execution or independent learner understanding.

## Continuity without a required state system

If actual authorized persistent records exist, consult the relevant current record, later corrections and dates before resuming. Identify real conflicts, preserve history and ask when resolution needs the learner's input. Do not invent a completed package, claim a verified state transition, or upgrade an agent explanation into learner evidence. A session boundary alone does not require a new diagnostic or negate prior work.

For a compact handoff include only what matters: goal and whether learner-confirmed; actual edition and accessible source; current package/window; prior substantive learner reconstruction and calibration; contact basis (reported, independent evidence, assumption from assigned reconstruction, or unknown); unresolved hinge and deferred bridge plus trigger; next feasible action; do-not-repeat items. If a host cannot save, output this as a user-copyable draft and explicitly state it has not been persisted. A user's statement of contact does not establish acceptance of a separate calibration.

## Permissions and access

Do not infer tools, file access, external network, long-term memory, platform support, source rights, or project state from this document. Use only a capability the host actually provides and the user permits. For new external copies respect copyright and access restrictions; a user-provided source may be examined within the permission given. Do not overwrite originals. If source extraction is unavailable or unreliable, ask for readable material or a specific passage; never fabricate text, OCR, pagination or tool outcomes.
